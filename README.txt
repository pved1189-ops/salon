STEP-BY-STEP HOSTINGER DEPLOYMENT GUIDE
------------------------------------------------------------------------

STEP 1: Log in to Hostinger
- Go to https://www.hostinger.com and log into your account.
- Click "Websites" in the top menu and click "Manage" next to your domain.

STEP 2: Open File Manager
- Under the "Files" section, click on "File Manager".
- Choose "Access files of [your domain]".
- Double click to enter the "public_html" directory.

STEP 3: Clear any default Hostinger placeholder files
- If you see a file named `default.php` or `index.php` generated by Hostinger,
  delete or rename it so it doesn't conflict with your `index.html`.

STEP 4: Upload the Website Files
Method A (Fastest & Recommended):
1. In Hostinger File Manager, click the "Upload" button (arrow pointing up in top right).
2. Select "File" and choose `Takdir-Hair-Style-Website.zip`.
3. Once uploaded, right-click `Takdir-Hair-Style-Website.zip` in File Manager and select "Extract".
4. Extract the contents directly into `public_html`.
5. Ensure `index.html` sits directly inside `public_html/` (not inside a subfolder).
6. You can now delete the `.zip` file from the server to save space.

Method B (Manual Folder Upload):
1. Unzip `Takdir-Hair-Style-Website.zip` on your computer.
2. In Hostinger File Manager, upload all files (`index.html`, `about.html`, etc.)
   and the `assets` folder directly into `public_html`.

STEP 5: Test Your Live Website
- Open your browser and visit: `https://yourdomain.com`
- Test the following:
  ✅ Header and navigation links across all pages
  ✅ WhatsApp appointment booking button (check if it opens WhatsApp)
  ✅ Phone call links
  ✅ "Our Work" gallery image lightbox and filter buttons
  ✅ Mobile responsiveness on your smartphone
